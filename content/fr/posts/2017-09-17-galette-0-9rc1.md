<p>Après de longs mois de développement, voici la toute première version de test publique pour la version 0.9 de Galette !</p>


<p>Cette nouvelle version majeure apporte, outre la correction de quelques bogues, un certain nombre de {{< doclink path="changelog.html#v090" branch="develop" >}}nouvelles fonctionnalités{{< /doclink >}} ; que je vous invite à découvrir en testant cette version :-)</p>


<p>Bien qu'il s'agisse d'une version majeure, aucune modification n'a été apportée à la base de données ; il suffit donc « simplement » de mettre à jour vos fichiers !</p>


<p>S'agissant d'une version de tests, les liens de téléchargement et la documentation font référence à l'actuelle version stable (0.8.3.4) ; une {{< doclink path="" branch="develop" >}}version de la documentation spécifique pour Galette 0.9{{< /doclink >}} a été mise en ligne sur la plateforme readthedocs ; même si la majorité des informations des anciennes versions reste tout à fait pertinente.</p>


<p>Notez que cette nouvelle mouture rend les plugins existants incompatibles... Les plugins officiels maps, paypal, fullcard et auto ont dores et déjà été migrés ; vous pourrez les tester en récupérant le fichier ZIP de leur branche develop sur github.</p>


<p>N'hésitez pas à tester cette nouvelle version et me faire des retours, soit sur <a href="{{< ref "contact" >}}">les listes de diffusion</a>, soit sur <a href="https://bugs.galette.eu/projects/galette/">le tracker</a> :-)</p>
