<p>Une faille de sécurité a récemment été rapportée pour les versions 0.63 de Galette (<a href="https://bugs.galette.eu/issues/250">https://bugs.galette.eu/issues/250</a> - CVE-2012-2338).</p>


<p><strong>La mise à jour de votre version de Galette ou du fichier qu corrige le problème est fortement recommandée.</strong></p>


<p>Cette vulnérabilité impacte toutes les versions de Galette 0.63. Galette 0.7 ainsi que l'actuelle version de développement ne sont pas touchées par cette faille.</p>


<p>Le problème a été corrigé, une version 0.63.4 de Galette est disponible (la seule modification concerne la faille en question) :<br />
<a href="https://galette.eu/download/archives/galette-0.63.4.tgz">https://galette.eu/download/archives/galette-0.63.4.tgz</a></p>


<p>Notez également qu'il s'agit de la toute dernière modification qui sera apportée aux versions 0.6x de Galette (qui passe donc EOL)&nbsp;: les développements, le support, etc. de ces versions ne seront plus assurés.</p>


<p>Galette 0.7 existe maintenant depuis plusieurs mois (et une <a href="https://bugs.galette.eu/versions/30">prochaine version est déjà sur les rails</a>)&nbsp;; nous vous encourageons à mettre à jour votre ancienne version ;)</p>
