<p>L'équipe de Galette est heureuse de vous faire part de la sortie de <a href="https://galette.eu/download/archives/galette-0.63.1.tgz">Galette 0.63.1</a>&nbsp;!</p>


<p>Il s'agit d'une version corrective, voici la liste des corrections apportées&nbsp;:</p>
<ul>
<li>certaines préférences n'étaient pas correctement initialisées à l'installation</li>
<li>sur certains hébergeurs, les fonctions exif ne sont pas disponibles, on utilise GD dans ce cas bogue #12836 (Gna!)</li>
<li>le XHTML était parfois mal formé en raison des sessions PHP bogue #13071 (Gna!)</li>
<li>correction de notices PHP dans les logs patch #1133 (Gna!)</li>
<li>suppression des fonctions posix qui sont dépréciées dans PHP 5.3</li>
<li>ajout d'un fichier .htcaccess pour interdire la lecture du dossier des images depuis le web</li>
</ul>

<p>Vous pouvez récupérer la dernière version à l'adresse&nbsp;: <a href="https://galette.eu/download/archives/galette-0.63.1.tgz">https://galette.eu/download/archives/galette-0.63.1.tgz</a></p>


<p>Si vous utilisez déjà Galette 0.63, vous n'avez pas à repasser par la case installation de nouveau, la base de données n'a pas été modifiée. Copiez juste les nouveaux fichiers et c'est fini ;-)</p>


<p>En cas de problème, vous pouvez <a href="https://bugs.galette.eu/projects/galette/">rapporter les bogues via l'interface de Gna!</a></p>


<p>La gentille équipe de développement de Galette.</p>
