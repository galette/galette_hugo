I'm very happy to announce release of Galette 1.1.4 version!

First of all, I'd like to thank [Institut d’Études Occitanes](https://ieo-oc.org/) for their features sponsoring 👍️

- Groups managers can add or list contributions and transactions
- Improve dashboard
- Activate choice after member creation for groups managers

I also want to thank [Association l'Aphyllanthe](https://www.aphyllanthe.fr/) because they have sponsored a brand-new [Activities management plugin](https://doc.galette.eu/en/master/plugins/activities.html)

This version also provides several bugfixes and a few other improvements:

- Install from command line
- Revert PDF member card to previous version, new adaptative one is optional
- Fix PDF footer overlaps
- Notify members when groups managers edit their account
- Preferences socials networks were removed on telemetry update
- Special HTML character are encoded on members search, therefore no results are found
- Begin membership date changes on keyboard browse
- Improve Preferences checks for membership extension/date
- Cannot remove emails from emails management
- Force image crop in preferences does not work
- Display PHP startup messages on error page
- Display max_input_vars configuration on sys info page
- Fix SQL issue with postgres searching on dynamic dates

All plugins have received updates (minor fixes or improvements, updated translations), so don't forget to update them too!

Happy Galette!
