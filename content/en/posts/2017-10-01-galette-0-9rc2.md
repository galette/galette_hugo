<p>Two weeks after the first one.. Here is a second public release for Galette 0.9!</p>


<p>A very, very big thanks to all people that have tested the verision; some bugs have been spotted, and they've of course been fixed in this new release!</p>


<p>Since the first RC, some minor improvements have been added:</p>
<ul>
<li>merge admintools plugin,</li>
<li>you now can use two years in members cards configuration.</li>
<li>you can search in status labels from free search.</li>
<li>use lists for statuses and genders in free search.</li>
</ul>


<p>Reminder...</p>


<p>This new major release brings, along with some bugfixes, some {{< doclink path="changelog.html#v090" branch="develop" >}}new features{{< /doclink >}} I invite you to discover testing this release :-)</p>


<p>Even if this is a major release, no changes have been done to the database; you "only" have to update your files!</p>


<p>Note that this new release makes plugins incompatibles.... Official plugins maps, PayPal, fullcard and auto have already been migrated; you can test them downloading the ZIP file of their develop branch on github.</p>


<p>Do not hesitate to test this new release, and give me feebdbacks; on <a href="{{< ref "contact" >}}">the mailing lists</a> or on the <a href="https://bugs.galette.eu/projects/galette/">le tracker</a> :-)</p>
