<p>After a few weeks... Here is a third public test release for Galette 0.9!</p>


<p>Once again, I'd like to thank every person involved in testing the previous version; <a href="https://bugs.galette.eu/projects/galette/issues?query_id=13">declared bugs have of course been fixed</a> in this new release!</p>


<p>Appart of those fixes; Galette 0.9 now has a system to send some data and to register. The goal is to retrieve some (<strong>anonymous!</strong>) useful information on Galette usages. You can find {{< doclink path="usermanual/generalites.html#telemetry" branch="develop" >}}more informations on telemetry in the documentation{{< /doclink >}}.</p>


<p>Reminder...</p>


<p>This new major release brings, along with some bugfixes, some {{< doclink path="changelog.html#v090" branch="develop" >}}new features{{< /doclink >}} I invite you to discover testing this release :-)</p>


<p>Even if this is a major release, no changes have been done to the database; you "only" have to update your files!</p>


<p>Note that this new release makes plugins incompatibles.... Official plugins maps, PayPal, fullcard and auto have already been migrated; you can test them downloading the ZIP file of their develop branch on github.</p>


<p>Do not hesitate to test this new release, and <a href="{{< ref "contact" >}}">give me feedback using one of the provided ways</a> :-)</p>
