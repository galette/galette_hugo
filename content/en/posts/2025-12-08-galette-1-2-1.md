I'm happy to announce the release of new Galette 1.2.1 release!

* Rework groups management user interface
* Several fixes and improvements on logo (webp transperency, logo display in mails, ...)
* Change default order on contributions and transactions
* Fix attaching existing contribution on transaction
* Fixes on PDF member cards
* Fix text emails signature
* Fix debug mode using release archives
* Minor fix on CSV exports
* Fix contributions creation from payments plugins
* Fix issues on some PostgreSQL sequences

See [Galette 1.2.1 changelog](https://doc.galette.eu/en/develop/changelog.html#v1210) for all details.

Almost all [plugins](https://doc.galette.eu/en/develop/plugins/) also have been updated, some issues have been fixed and langs updated.
