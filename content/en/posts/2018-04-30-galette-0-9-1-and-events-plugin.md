<p>A few months after the last major release, we are proud to announce the release of <a href="https://galette.eu/download/galette-0.9.1.tar.bz2">Galette 0.9.1</a>!</p>


<p>This new version provides some bug fixes, and a few new features:</p>

<ul>
<li>batch changes on members,</li>
<li>change sender on mailings,</li>
<li>choose default status for new members from preferences,</li>
<li>a text can be added on footer,</li>
<li>German translation.</li>
</ul>


<p>Full cangelog for Galette 0.9.1 is available at:<br />
{{< doclink path="changelog.html#v091" >}}Galette 0.9.1 full changelog{{< /doclink >}}</p>


<p>Along with this new release, a {{< doclink path="plugins/events.html" branch="develop" >}}plugin to manage events{{< /doclink >}}  is now available!</p>


<p>I'd like to thank very much all persons involed in this new release; and especially Arnold W. for the german translation, as well as "Association Bretonne des Amis de Saint Jacques de Compostelle
"  (https://www.compostelle-bretagne.fr/) which sponsored sender choice on mailing and the whole events plugin.</p>
