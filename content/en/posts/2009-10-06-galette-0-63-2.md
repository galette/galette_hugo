<p>The Galette Team is glad to announce the release of <a href="https://galette.eu/download/archives/galette-0.63.2.tgz">Galette 0.63.2</a>!</p>


<p>It's a corrective version, here are issues that have been fixed:</p>
<ul>
<li>membership's deadline was incorrect for a fiscal year (bug #13010 (Gna!))</li>
<li>donations didn't appear in the right color in the table (bug #13009 (Gna!))</li>
<li>history entries when adding or editing a contribution did not contains member's login - as when adding/editing a member (bug #13011 (Gna!))</li>
<li>on windows, some characters were incorrectly interpreted  - "\n" for example (bug #14162 (Gna!))</li>
<li>when saving a picture (PNG format), alpha channel was not saved, causing image to get a default background color (bug #14327 (Gna!))</li>
<li>restrictions showing pictures (since 0.63.1) prevents custom logo to display correctly (bug #14442 (Gna!))</li>
<li>when editing member's language, current session was also translated (bug #14443 (Gna!))</li>
<li>some characters - like simple quotes - were badly encoded mailings subjects (bug #14449 (Gna!))</li>
<li>mail sending were always active, even if disabled in preferences (bug #14450 (Gna!))</li>
</ul>

<p>You can now download the latest release from: <a href="https://galette.eu/download/archives/galette-0.63.2.tgz">https://galette.eu/download/archives/galette-0.63.2.tgz</a></p>


<p>If you're already using Galette &gt;= 0.63, you do not have to upgrade, database was not modified. Just copy the new files and you're done ;-)</p>


<p>As usual, you can <a href="https://bugs.galette.eu/projects/galette/">report bugs through the Gna! interface</a>.</p>


<p>The very kind Galette developpers.</p>
