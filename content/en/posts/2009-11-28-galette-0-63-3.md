<p><a href="https://galette.eu/download/archives/galette-0.63.3.tgz">Galette 0.63.3</a> is cooked, lunch's ready ! :-)</p>


<p>This version fixes a security flaw found in the demonstration. Here is the changelog:</p>
<ul>
<li>fix a security flaw that allowed attacker to send arbitrary PHP files on some servers</li>
<li>when sendind invalid member form, line dynamic fields were repeated (bug #10187 (Gna!))</li>
<li>some encoding issues has been noticed on UFT-8 MySQL servers. Connection is now forced to LATIN1 (thanks to Cédric)</li>
<li>unbreakable spaces appears on non html email (thanks to Cédric)</li>
<li>using XML characters in mailing subjects causes XML analysis errors on preview (bug #14571 (Gna!))</li>
<li>needless data were stored into logs (and not at the right place) sending mailings (bug #14569 (Gna!))</li>
<li>XML analysis errors where thrown on logs page when a member card contains reserved characters (bug #14561 (Gna!))</li>
<li>html tags in mailing were not showed while previewing a mailing under Firefox (bug #14465 (Gna!))</li>
</ul>
